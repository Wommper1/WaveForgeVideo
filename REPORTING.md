# Reporting a WaveForgeVideo problem

Open [a GitHub issue](https://github.com/Wommper1/WaveForgeVideo/issues/new) with a clear title and the details below. Search existing issues first. A GitHub account is needed; for a private inquiry use [wommper1@gmail.com](mailto:wommper1@gmail.com).

- App version and whether you used the release ZIP or source.
- Windows version (or another, untested operating system).
- FFmpeg version and how the app found it.
- Steps to reproduce; expected result; actual result and exact error.
- Export preset, trim range, input format and whether a small non-private sample reproduces it.
- A redacted export log or screenshot if useful. Logs/settings live in `%APPDATA%\WaveForgeVideo` unless `WAVEFORGE_HOME` overrides it.

Do not attach private videos, identifying folder paths, credentials or personal information. Review logs before posting. Report security concerns privately by email rather than including exploit details in a public issue. This guide does not promise a response time.

For a feature idea, explain the task you want to complete and how you currently work around it. For code changes, see [CONTRIBUTING.md](CONTRIBUTING.md).
